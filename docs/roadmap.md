# Roadmap

## Near term
- Stable interceptor support for requests and httpx sync.
- Clear error messages when interception cannot be applied.
- JSON report schema and CLI summary output.

## Future enhancements
- Async httpx interception.
- Additional client support (aiohttp, urllib.request).
- Deeper schema coverage at the field level.
- Ignore rules with regex or glob patterns.
- Interactive HTML reports.
- Contract violation reporting based on validation errors.
- Spec version comparison for coverage regression tracking.
